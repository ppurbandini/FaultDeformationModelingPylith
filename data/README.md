# Data Sources

The PyLith simulation data used in this project are based on the Nepal kinematic model provided by the Computational Infrastructure for Geodynamics (CIG).

Original data and simulation setup:

https://cuseistut.readthedocs.io/en/latest/pylith_static/

The original mesh, spatial databases, configuration files, and simulation outputs are available from the source above.

To avoid duplicating the original dataset, these files are not included in this repository.

Custom Python scripts, figures, and analyses generated from the simulation are included in this repository.

Please refer to the original source for further information about the simulation setup and data.
